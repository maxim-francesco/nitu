# Nițu Auto Park

Website-ul oficial pentru Nițu Auto Park - Dealer premium de mașini rulate în Câmpina.

## Tehnologii Utilizate

Acest proiect este construit cu:
- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Cum se rulează proiectul local

1. Instalează dependențele:
   ```sh
   npm install
   ```

2. Pornește serverul de dezvoltare:
   ```sh
   npm run dev
   ```

3. Construiește proiectul pentru producție:
   ```sh
   npm run build
   ```
