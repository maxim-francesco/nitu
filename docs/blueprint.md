# **App Name**: Minimalist Launchpad

## Core Features:

- Content Display: Display a simple 'Hello, World!' message.

## Style Guidelines:

- Primary color: Soft Blue (#A0C4FF) to give a calm feel.
- Background color: Light gray (#F0F0F0) to not distract from the text.
- Accent color: Deeper blue (#75A0E0) for contrast.
- Body font: 'Inter', sans-serif, for clean readability.
- Center the 'Hello, World!' text for simplicity.
